# Homework 1

Instructions:
- Modify the `Exercises/Problems.lean` file to solve the exercises.
- You may create new files, but don't modify any existing ones.
  - Except `Problems.lean`, of course.
- You can see your progress with `lake build`.
- To submit the exercise, just commit and push.
  - You can do this multiple times.
  - However, to prevent abuse we will only grade it once per six hours.
  - This means any submission in the last 6 hours before the deadline is final.
- You can look at the web version of the repository to check
  that your changes are correct, and that the GitHub action
  succeeded.

Note that if your assignment fails to build when you submit it, you will
not receive any points.
